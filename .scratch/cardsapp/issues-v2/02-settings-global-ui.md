# 02 - Settings, Splash & Global UI

**What to build:**
- **Splash Screen:** Holds for 2-3 seconds, displays "Welcome" and today's date. Transition state shows "cards not reviewed today" and "cards reviewed today".
- **Settings Modal:** Input for AI models, API keys, and Corpus API password.
- **Until Date:** Logic to push the "Until" date 31 days forward whenever the Corpus API password is updated. Displayed in top left of Dashboard.
- **Global Search:** Search bar in the top navigation/dashboard to search the entire database (Chinese and English) and jump to results.

**Status:** done
